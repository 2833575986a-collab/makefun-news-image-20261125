Entry for the [make.fun bounty news-image-20261125](https://make.fun/bounty/news-image-20261125). `main.ts` (Node 22, standard library only) lays out six stories from Wednesday 25 November 2026 and draws the page itself, using the canvas, 5x7 bitmap font and PNG encoder in `image.ts`. It writes `/output/entry.png`. No network, no clock, the same bytes every run.

```
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
